# Tower Invasion

2D action-игра на Unity: исследование, бой и инвентарь. Игрок бьёт, блокирует, уворачивается и усиливает удары, вокруг — враги леса и лагерь.

## Стек

- Unity `6000.0.44f1`
- C#, TextMesh Pro
- Скрипты игрока: движение, атака, блок, перекат, сильный удар, статы, стейт-машина
- Враги: `Assets/Scripts/Mobs` (классы врагов, лесные мобы, снаряды)
- UI: инвентарь и меню

## Что есть в игре

- Бой ближнего боя и камера, которая следует за игроком
- Здоровье, анимации, костёр (`Bonfire`)
- Инвентарь и меню
- Набор врагов и снарядов

## Как открыть

1. Поставь Unity `6000.0.44f1`.
2. Открой папку репозитория как проект.
3. Запусти сцену из `Assets/Scenes`.
